# Seal Browser for Android / Samsung

Version 1.1 matches the minimal iPhone UI much more closely.

Highlights:
- Bottom address bar and navigation controls
- Black / system-grey / blue visual language
- Two-column tab switcher with live page previews
- Saved/restored tabs
- English Google search (UK region)
- JavaScript, cookies, DOM storage, pop-up tabs
- Inline/fullscreen web video support including YouTube Shorts
- Android 8.0+ (API 26+)

## Build on GitHub
Upload the project contents to a repository, make sure `.github/workflows/build-android-apk.yml` exists, then run **Build Seal Browser Android APK** from the Actions tab.
